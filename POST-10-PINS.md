## ONE-TIME SETUP (do once, 10 minutes)
---------------------------------------------------------------------
1. Open Canva -> Create a design -> search "Pinterest Pin" (1000 x 1500 px).
2. Pick a clean template. Make it simple: big text, one photo, plain background.
3. Add your handle small at the bottom:  @ordinarydayinyourlife
4. Rename the design "TEMPLATE". You will copy it for every pin:
   top menu -> File -> Make a copy.

---------------------------------------------------------------------
## THE SAME 2 PARTS FOR EVERY PIN
---------------------------------------------------------------------
PART A — MAKE THE IMAGE (Canva, ~3 min)
  1. Open TEMPLATE -> File -> Make a copy.
  2. Replace the big text with the MAIN TEXT of that pin (keep the line breaks).
  3. Replace the small line with the SUBTEXT.
  4. Replace the photo: left sidebar -> Photos -> search the PHOTO SEARCH words.
     Pick a different photo for every pin (do not reuse one).
  5. Share -> Download -> File type PNG -> Download.

PART B — PUBLISH (Pinterest, ~2 min)
  1. pinterest.com -> Skapa (Create) -> Skapa pin (Create Pin).
  2. Upload the PNG you just downloaded.
  3. Titel:        paste the TITLE.
  4. Beskrivning:  paste the DESCRIPTION.
  5. Länk:         paste  https://ordinarydayinyourlife.netlify.app/
  6. Anslagstavla: choose  Zero waste kitchen swap
  7. Leave these ALONE (do not touch):
       - Tagga produkter / Lägg till produkter   (leave empty)
       - Lägg till en produktlänk                (leave empty)
       - Markera som AI-modifierad               (leave OFF)
       - Denna pin innehåller en AI-genererad person (leave OFF)
  8. Optional: under "Taggade ämnen" add: zero waste, sustainable living.
  9. Click  Publicera.
